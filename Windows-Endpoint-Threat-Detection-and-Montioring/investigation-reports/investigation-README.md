# Windows Endpoint Investigation Reports

This directory contains investigation reports based on security events collected from the Windows 11 endpoint through Wazuh.

## 1. Investigation Reports

| Report | Activity | Windows Event / Capability |
|---|---|---|
| 01 | Failed logon investigation | Event ID 4625 |
| 02 | Successful logon investigation | Event ID 4624 |
| 03 | Local account creation investigation | Event ID 4720 |
| 04 | Local account deletion investigation | Event ID 4726 |
| 05 | File Integrity Monitoring investigation | Wazuh FIM |
| 06 | PowerShell activity investigation | Event ID 4104 |

## 2. Report Contents

Each investigation report will document:

- Investigation objective
- Event identification
- Event timestamp
- Affected endpoint
- Relevant event fields
- Observed activity
- Security significance
- Investigation analysis
- Supporting screenshot references
- Investigation conclusion
- Limitations

Reports will be based on actual events and available evidence from the lab. No unverified conclusions or detection claims will be included.
